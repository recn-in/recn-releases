# RECN — Releases

Installers for the RECN desktop apps. RECN is currently distributed as beta
software; there is no stable channel yet. Installed apps update themselves.

## RECN Rec

- **macOS Beta:** [RECN-Rec-Beta-macOS.dmg](https://github.com/recn-in/recn-releases/releases/download/v0.0.2-beta/RECN-Rec-Beta-macOS.dmg) — signed + notarized, drag to Applications.
- **macOS via Homebrew:** `curl -fsSL https://raw.githubusercontent.com/recn-in/recn-releases/main/install.sh | bash` — taps, trusts, and installs or updates the `recn-rec` cask.
- **Windows Beta:** [RECN-Rec-Beta-Windows-Setup.exe](https://github.com/recn-in/recn-releases/releases/download/v0.0.2-beta/RECN-Rec-Beta-Windows-Setup.exe) — installs per-user, no admin required.

## RECN Work

- **macOS Beta:** [RECN-Work-Beta-macOS.dmg](https://github.com/recn-in/recn-releases/releases/download/work-v0.0.2-beta/RECN-Work-Beta-macOS.dmg) — signed + notarized, drag to Applications.
- **macOS via Homebrew:** `brew tap recn-in/recn https://github.com/recn-in/recn-releases && brew install --cask recn-work`.
- **Windows Beta:** [RECN-Work-Beta-Windows-Setup.exe](https://github.com/recn-in/recn-releases/releases/download/work-v0.0.2-beta/RECN-Work-Beta-Windows-Setup.exe) — installs per-user, no admin required.

Beta Nightly builds contain the newest merged changes and are available from
the [releases page](https://github.com/recn-in/recn-releases/releases)
(`v*-beta-nightly.*` for Rec, `work-v*-beta-nightly.*` for Work).

Website: [recn.app](https://recn.app)
